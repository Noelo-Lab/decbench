The prelude defines Ghidra's byte-width scalar names (`undefinedN`, `intN`, and `uintN`) with matching storage widths, plus the common libc/POSIX aggregate layouts that appear without headers. It also supplies opaque or ABI-sized aliases for runtime types such as streams, directories, pthread objects, signal sets, regex state, vectors, and variadic-list storage. These declarations provide C spellings and preserve the observed member widths; they do not provide implementations.

The helper prelude maps Ghidra's size-encoded `CONCAT`, `SUB`, zero/sign extension, carry, signed-carry, and signed-borrow operations to casts, shifts, and GCC overflow builtins of the corresponding widths. The unusually wide vector extension/extraction helpers use unions to copy the represented low lanes without changing their bits.

Library declarations cover routines whose return ABI is significant, especially pointer, floating-point, `size_t`, and offset returns. Exact prototypes are used where the emitted calls consistently support them; translation functions whose source-level argument counts vary are intentionally declared in old-style form so their pointer return remains correct without rejecting valid emitted calls.

Sibling analysis recovers a callee's return spelling from the other Ghidra functions in the same binary and emits an old-style declaration, retaining the return register convention while tolerating Ghidra's inconsistent parameter lists. Calls assigned to typed pointer, word, floating, or vector locals provide additional return-type evidence, and routines also used as callback values are declared before that bare use.

Dialect rewriting sanitizes punctuation in autogenerated labels, converts Ghidra switch-table namespace notation to the underlying data label, supplies generated anonymous-union aliases, and separates libc structure tags from same-named functions. Signal-handler union accesses and synthetic `._offset_width_` fields become typed lvalues at the same byte offset, including pointer-valued synthetic fields.

Array-shaped 8-, 12-, 16-, 32-, and 64-byte temporaries are converted to width-matched scalars or GCC vector objects only when assignments or synthetic lanes prove value use; genuine buffers remain arrays. This includes arrays of 16-byte tuple elements. Array casts, whole-value assignments, lane subscripts (including byte indexing through converted pointers-to-16-byte values), and a common vector-buffer end-pointer expression are rewritten to equivalent typed loads, stores, and address arithmetic.

Local pointer correction applies only when a placeholder integer local is demonstrably dereferenced. Recursive definitions containing Ghidra calls with omitted live-register arguments are written in equivalent GNU old-style definition syntax, which preserves the named parameters and body while allowing those unprototyped recursive call sites; a recursive result consumed as a pointer similarly corrects a `void` placeholder return. Redundant casts on structure-valued `timespec` calls are removed so sibling/use inference can express the actual structure return convention.

Global recovery scans identifiers not declared by the isolated function and infers storage shape from strong uses: subscripting, dereference (also through an explicit scalar cast), member access, address-only use, pointer casts, assignments from allocators, function-pointer assignment, string APIs, wide constants, and floating arithmetic. Directly dereferenced data labels and indexed labels receive explicit object declarations, while known locals, tags, labels, members, functions, and keywords are excluded. The repair hook performs the same conservative inference for any undeclared identifier reported by GCC on a later attempt. Ghidra's direct bit test of a standard stream is normalized to the ABI-equivalent `_flags` member, and opaque callback/internal pointer names are supplied only as types.
