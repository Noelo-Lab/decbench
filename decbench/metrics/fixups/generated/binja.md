The prelude supplies the fixed-width integer vocabulary, Binary Ninja pseudo-types (including odd-width integers, its wide vector-like integers, and `int80_t`), GNU `error_t`/argp vocabulary, a layout-compatible glibc `FILE`, common string/stdio declarations, and small ABI structures such as `__va_list_tag`.  System headers are included only when emitted code mentions their public types (including dirent, getopt, regex, networking, locale, terminal, and register structures), avoiding unrelated prototype conflicts while giving recovered libc structures their real layouts.

Syntax normalization removes Binary Ninja register-location and non-C analysis annotations, makes SSA condition suffixes legal identifiers, translates signed/unsigned IL operator prefixes to C operators, repairs const-qualified pointer-to-array and pointer-to-function return declarators, and normalizes libc typedef spellings.  It restores braces around declaration control-flow arms, supplies null statements after otherwise empty labels, uniquely names repeated unreferenced IL labels, terminates bare member expression statements, maps known public structure fields, and uses the ABI-equivalent unsuffixed `readdir` interface on x86-64.

Literal normalization escapes Binja's doubled quote boundaries, literal `\x` text that would otherwise start a C hex escape, embedded quotes identified by GCC, and actual newlines split across emitted string lines.  These rules preserve the bytes represented by the decompiler rather than dropping malformed format arguments.

Symbol recovery declares address-named `data_…` objects according to their observed use (scalar, array, pointer, callable, or an assignable function-pointer variable) and non-sibling `sub_…` values used as code pointers.  Calls to emitted sibling functions use the sibling's recovered signature; calls without a usable sibling signature infer their return type from the receiving local, direct dereference, array use, or tail-return context.  This avoids implicit-`int` truncation while deliberately retaining unspecified argument lists where the decompiler does not support a faithful prototype.

Untyped-memory recovery casts only dereferences whose base Binary Ninja typed as `void *`, choosing the access width from a destination type when available and otherwise using the x86-64 machine word represented by the IL.  Constant offsets through recovered structure pointers remain byte offsets, jump-table addresses use normal array decay, callback-shaped scalars are retyped as function pointers, and indirect calls through integer fields are cast at the call site.  Binary Ninja's little-endian `*(&(rvalue)+offset)` is expressed as an equivalent shift and byte extraction.

Register-shape normalization represents Binja's 32-byte `zmm` byte arrays as its 256-bit vector pseudo-type.  This permits whole-register initializers and assignments while leaving explicit lane expressions intact.

The diagnostic repair pass is location-driven and runs only after GCC proves a construct invalid.  It declares remaining symbols from observed shape (preferring pointers over unsized arrays when assignments require it), explicitly declares implicit-int calls rejected inside C17 loop initializers, casts non-integral subscripts, double-`void` dereferences, indirect calls, switch quantities, and pointer-shaped raw-bit arithmetic through integer types, and repairs lvalue stores and unary operations at the reported column.  Pointer destinations overwritten by scalar SSA values retain those bits through `uintptr_t`; floating temporaries reused as pointer stack slots and misclassified raw `FILE` storage are likewise retyped only after GCC reports the incompatible assignment.  Mismatched sibling arity or return types are adapted at the call site, array-cursor stores and vector splats retain their original values, and conflicting synthetic prototypes yield to system headers; no repair deletes or stubs an expression.
