# Fixup rule notes

**Basic dialect and types.** The preparer removes angr's `::0x...::` loader qualification, gives its angle-bracketed IR/stack temporaries consistent valid C identifiers, defines `NULL` only when needed, and supplies fixed-width integer, 128/256-bit, and signal-handler pseudo-types only when the translation unit uses but does not define them. An object declared as `extern void` is changed to an unsigned-byte object because C permits `void` only as a function return/incomplete pointee, while angr uses such globals as byte-addressed storage.

**Recovered struct declarations.** angr can emit typedef-struct definitions before by-value dependencies and can use a typedef before its definition. The fixup adds matching forward typedefs and topologically orders only complete by-value definitions; pointer dependencies remain forward-declared. Scalar-to-aggregate casts are represented as stores through the aggregate's address, retaining the recovered object representation instead of inventing fields.

**Offset fields and padding.** Names such as `field_18` and `padding_c` encode byte offsets. Accesses to omitted fields, fields through `void *` or non-struct pointers, scalar fields that angr subsequently treats as pointers, and continued offset chains are lowered to byte-address calculations followed by a load of the requested recovered word. Existing declared members are left alone; omitted padding remains a byte pointer so its following subscript keeps byte semantics.

**Void pointers and pseudo-arrays.** A casted subscript of a `void *` is interpreted as a typed load at the indicated byte offset, and a direct dereference becomes a word lvalue. angr's display-only array casts and array-shaped scalar temporaries are converted to their element/pointer form where usage proves that interpretation; an array type used in an address-based representation cast becomes a pointer to its leading element, and a scalar cast under unary dereference receives the missing pointer star. Zero assignment to an aggregate array element becomes an equal-size zero fill, and diagnostic repair copies the RHS object representation into array lvalues that C cannot assign directly.

**Function and global declarations.** Sibling definitions provide return types for referenced sibling functions when their types are available in the current unit; callback-only sibling names receive an old-style `int ()` declaration. Common libc routines receive ABI-accurate pointer, integer-width, or floating return types without prototypes, preserving angr's argument setup while preventing implicit-`int` truncation. Calls assigned directly to recovered pointers infer `void *` only when no sibling or known runtime declaration applies. Diagnostic repair imports exact extern globals from siblings, falling back to a word-sized declaration only for angr's generic `g_...` globals.

**Indirect calls and namespace collisions.** Integer/data-pointer objects and members invoked by angr are cast to old-style function pointers, including balanced scalar-load expressions, indexed callback tables, dereferenced callback slots, and conditional callee expressions. If a typedef and ELF function share a name, the function gets a private C identifier with an `asm` symbol name, leaving the target symbol and typedef intact. Address-based type puns of flat or nested helper-call rvalues use a GNU statement-expression temporary so the call occurs once and its bits, rather than its numeric value, are reinterpreted.

**Pointer arithmetic and control values.** Pointer values are converted to `unsigned long` only for integer-only masks, shifts, heterogeneous subtraction, and similar operations rejected by C; ordinary pointer arithmetic is retained. Integer compound updates of pointer-shaped temporaries instead operate on the pointer object's address-sized representation so the result remains an lvalue. Known pointer-returning calls and explicit `void *` addresses used arithmetically expose their address value. Array/pointer switch quantities are converted to their scalar value, recovered variable-valued gotos become GNU computed gotos, and angr's whitespace-free `&&local` spelling is reduced to `&local` so GNU C does not parse it as a nonexistent label address.

**Bitvector concatenation.** angr prints VEX-style concatenation as the infix non-C form `high CONCAT low`. The fixup represents it in `uint128_t` by shifting the high operand by the recovered low width and ORing in the low operand. The common `_INSERT(high CONCAT 0, 0, value)` form is lowered directly to the same concatenated value with `value` occupying the zeroed low half, avoiding a fictitious helper call.

**Minor syntax recovery.** A standalone single-line helper call for which angr omitted the semicolon is terminated, pointer dot access is changed to arrow access based on declarations, padding arrays used as scalar bitfields select their first byte, and calls through loaded code addresses are made explicit. These rules add syntax or typing but do not remove statements or replace unsupported expressions.

**Diagnostic repairs.** On failed compiles only, gcc line diagnostics guide narrowly scoped conversions: rejected pointer/member/address operands become address-sized integers, casted assignment targets become typed representation lvalues, incompatible aggregate assignments become raw word stores, aggregate scalar and unary uses load their leading recovered word, missing encoded-offset members become byte-offset accesses, pointer-valued subscripts become address-sized indices, and address words used as subscript bases become byte pointers. When angr models an inline stack array as its first scalar slot, a typed `&slot[index]` access is regrouped so the element-pointer cast occurs before indexing. A recovered pointer-to-pointer gets the extra dereference only when gcc diagnoses its member access, while an address cast that accidentally moved a following member selection outside its parentheses is regrouped around the complete member. Similarly, an address-shaped call or member chain used with `->` is cast to the unique recovered aggregate type containing the selected field. Undeclared callbacks and globals are then declared. Repairs preserve line count until declaration insertion so later diagnostics remain attributable and stop when no recognized error can be changed.
